# p6-watchdog

Страж агента сверки заявок. Только читает: статус запусков агента (GitHub API) и состояние бота (Telegram API). Тревоги — в личный чат.

Секреты репозитория: `TELEGRAM_BOT_TOKEN`, `ALERT_CHAT_ID`, `GH_READ_TOKEN` (fine-grained, только Actions: Read для p6-reminder).

Проверки (рабочее время 09:30–17:30 МСК, будни по производственному календарю):
- агент не запускался больше 20 минут;
- два последних запуска подряд завершились ошибкой (одиночный сбой не тревожит);
- в логе агента ошибка отправки в Telegram;
- токен бота не работает или бота убрали из чата отдела (проверяется всегда);
- осталось меньше 100 бесплатных минут GitHub Actions (оценка по длительности запусков, повтор раз в 6 часов).

Запуск: workflow_dispatch каждые 15 минут через cron-job.org. Повтор той же тревоги — не чаще раза в час.
