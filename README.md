# p6-watchdog

Страж агента сверки заявок. Только читает: статус запусков агента (GitHub API). Тревоги и сводка в 18:00 — в Битрикс24 личным сообщением от бота «Helper for 1St» (секрет BITRIX_WEBHOOK; другой адресат — секрет BITRIX_ALERT_DIALOG). Telegram — запасной канал, если Битрикс недоступен.

Секреты репозитория: `TELEGRAM_BOT_TOKEN`, `ALERT_CHAT_ID`, `GH_READ_TOKEN` (fine-grained, только Actions: Read для p6-reminder).

Раз в день в 18:00 (будни) присылает итоговую сводку по поставщикам: заявки, закрытые сверкой, и три группы (ответили на все / частично / не отвечают).

Проверки (рабочее время 09:30–17:30 МСК, будни по производственному календарю):
- агент не запускался больше 20 минут;
- два последних запуска подряд завершились ошибкой (одиночный сбой не тревожит);
- в логе агента ошибка отправки в мессенджер;
- токен бота не работает или бота убрали из чата отдела (проверяется всегда);
- новые письма, которые агент не смог разобрать («⚠️ … в чат не отправляется»), приходят в Битрикс24;
- напоминание ушло поставщику, от которого сегодня уже было письмо;
- осталось меньше 100 бесплатных минут GitHub Actions (оценка по длительности запусков, повтор раз в 6 часов).

Запуск: workflow_dispatch каждые 15 минут через cron-job.org. Повтор той же тревоги — не чаще раза в час.
